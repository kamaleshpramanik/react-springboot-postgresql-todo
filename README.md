# 📝 Todo App – React + Spring Boot + PostgreSQL

A simple full-stack Todo application built with **React (frontend)**, **Spring Boot (backend)**, and **PostgreSQL**.  
This project demonstrates basic CRUD operations, REST API integration, and a clean minimal UI.

---

## 🚀 Features

- Add new todos
- Mark todos as completed (checkbox)
- Edit todo text
- Delete todos
- Persistent storage using PostgreSQL
- RESTful API with Spring Boot
- Clean and minimal UI with React

---

## 🛠 Tech Stack

### Frontend
- React
- Axios
- CSS (minimal custom styling)

### Backend
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
